ReconPro Lite

A secure, browser-based reconciliation utility. Compares your company ledger against a bank or GST statement — both sides are fully analysed, including bank-only entries.

All data stays on your device — zero uploads, zero storage.
How It Works
  • 1Upload your Company Ledger (File A) and Bank / GST Statement (File B) — both must be .xlsx or .xls.
  • 2Each file's first row must contain column headers. The tool auto-suggests column matches.
  • 3Map the corresponding columns across both files. Add more pairs for higher accuracy.
  • 4Click Run Reconciliation. Results will classify every row from both files.
  • 💡New: Bank-only entries (present in File B but absent in File A) are now shown as first-class results — not buried in a secondary table.
