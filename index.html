Client-Side Application · No Server · No Data Transmission

ReconPro Lite

A secure, browser-based reconciliation utility for comparing a company ledger against a bank or GST statement. All processing is performed locally within this session.

All data remains on your device. Files are processed in local memory and discarded upon closing this tab.
Before You Begin
  • 1Upload two Excel files: the Company Ledger and the GST / Bank Statement.
  • 2Ensure the first row of each Excel file contains the correct column headers.
  • 3After both files are uploaded, map the corresponding columns carefully.
  • 4Click Run Reconciliation to generate the results.
  • 💡Selecting more matching fields improves reconciliation accuracy.
